# cpp-featured
My default header lib for better C++

# Features
|Name|Purpose|
|:-|:-|
|[io.h](/include/io.h)|Adds easier println function|
|[panic.h](/include/panic.h)|Adds rust-like panic's if you need them|
|[string_view.h](/include/string_view.h)|Adds rust-like string types, and make strings safer with conversion & UTF8|
|[temp_alloc.h](/include/temp_alloc.h)|Adds tmalloc for temporal allocation, inspired by [C3](https://c3-lang.org/language-common/memory/)|
